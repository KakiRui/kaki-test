提示词里的 {total} 会自动替换成当前档位的数字范围。提示词只保存在当前浏览器和当前网址；本地文件与 GitHub 链接的保存记录彼此独立。
📷 上传 / 拖入聊天记录截图；也可以直接 Ctrl+V 粘贴截图
按下面的 #1、#2、#3 顺序识图；可调整顺序。普通手机截图会原图直传；显示红色尺寸表示图片宽度偏小，昵称可能看不清，建议换清晰原图。
导入位置：当前档位。会自动跳过已占用编号；同一个编号被多人认领时，只算给聊天记录中时间更早的人。网页按“截图顺序 → 消息时间递增 → 截图内行号”排序，结果先预览，不会直接写入。
